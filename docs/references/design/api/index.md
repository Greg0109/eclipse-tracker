    This document is designed for managers and engineers.

    regarding the API design.

The developed API must be compliant with this design.
The developed API is autogenerated
and you can find it in [integration](site:references/integration/api) section.

## OpenAPI Specifications

OpenAPI is a standard used for describing (RESTful) APIs.
It specifies the endpoints, request/response models,
and authentication methods in a machine-readable format,
enabling both humans and computers to discover and understand the capabilities of the service
without access to source code, documentation, or through network traffic inspection.
